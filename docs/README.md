# Hero Banner Slider for Magento 2 documentation

Online version: <https://www.coullworks.com/docs/magento/hero-banner-slider>

## Pages

- [Overview](overview.md): What Hero Banner Slider does: responsive hero banners and sliders managed in the admin and placed with Page Builder or widgets. Free for your own store.
- [Install](install.md): Add the module with Composer, enable it and run the Magento setup commands. Requires Magento 2.4.7 to 2.4.9 on PHP 8.2 to 8.5. Hyvä is not supported.
- [Get started](get-started.md): Create a banner, put it on a CMS page with the widget and see it on the storefront. No code needed.
- [Changelog](changelog.md): Release history for the Hero Banner Slider module for Magento 2, newest first, with what changed in each version.
- [Configure](configure.md): The one setting the module has, Enable, where to find it and what it does. Everything else is per banner and slider.
- [Banners](banners.md): The Banners grid and form: every column, button and field, the desktop and phone images, the enabled switch and the overlay editor.
- [Sliders](sliders.md): The Banner Sliders grid and form: every column and field, and how the ordered slides list works.
- [Widgets](widgets.md): Place a banner or slider on a CMS page, a category description, a static block or in layout XML. Every widget parameter explained, with screenshots.
- [Page Builder](page-builder.md): Drop a Hero Banner or Banner Slider on the Page Builder stage, set every option, and see the result on the storefront.
- [Permissions and roles](permissions.md): The resources the module adds, what each one allows, and a worked example of a limited editor role.
- [Migration from BoxLeaf](migration.md): What is copied from boxleafdigital/module-bannerslider, what is not, and the manual steps to switch over.
- [Images](images.md): How the module resizes banner images, serves WebP, picks the phone image and keeps the hero fast for LCP.
- [How it behaves](behaviour.md): The fixed slider behaviour, tabs, parallax, two sliders on a page, accessibility and when nothing renders.
- [CSS hooks](css-hooks.md): The classes the module renders, the theme variables it uses and the bundled Slick library, so you can style banners in your theme.
- [Reference](reference.md): Database tables, the admin route, layout handles, the PHP service contract, and the things the module does not have.
- [Troubleshooting](troubleshooting.md): Fixes for banners that do not show, empty arrow squares, broken layouts, missing images and access denied errors.
- [Upgrade](upgrade.md): Update with Composer, and what changed in 2.1.0 and 2.1.1 that needs your attention, including roles.
